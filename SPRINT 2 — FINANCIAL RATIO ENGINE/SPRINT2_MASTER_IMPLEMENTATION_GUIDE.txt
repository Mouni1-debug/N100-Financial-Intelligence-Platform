KEY FORMULA (D/E):
  if borrowings = 0: return (0.0, None)  # Debt-free
  if equity = 0: return (None, None)
  de = borrowings / equity
  if sector ≠ "Financials" and de > 5: flag = True
  else: flag = None
  return (de, flag)

KEY FORMULA (ICR):
  if interest = 0: return (None, "Debt Free", None)
  icr = (op_profit + other_income) / interest
  if 0 < icr < 1.5: warning_flag = True
  return (icr, None, warning_flag)

6 EDGE CASES:

1. Normal (Positive → Positive):
   Compute CAGR normally
   CAGR = ((end/start)^(1/n) - 1) × 100
   flag = None

2. Decline to Loss (Positive → Negative):
   Return None, flag = "DECLINE_TO_LOSS"
   Example: PAT 500 → -100

3. Turnaround (Negative → Positive):
   Return None, flag = "TURNAROUND"
   Example: PAT -500 → 100

4. Both Negative (Negative → Negative):
   Return None, flag = "BOTH_NEGATIVE"
   Example: PAT -500 → -100

5. Zero Base (Start = 0):
   Return None, flag = "ZERO_BASE"
   Can't divide by zero

6. Insufficient Data (<n years):
   Return None, flag = "INSUFFICIENT_DATA"

Pattern                   Signature    Meaning
────────────────────────────────────────────────────────────────────

KEY FORMULAS:

FCF = CFO + CFI
CFO Quality = Avg(CFO 5yr) / Avg(PAT 5yr)
  > 1.0 = "High Quality"
  0.5-1.0 = "Moderate"
  < 0.5 = "Accrual Risk"

CapEx Intensity = abs(CFI) / Sales × 100
  < 3% = "Asset Light"
  3-8% = "Moderate"
  > 8% = "Capital Intensive"

FCF Conversion = FCF / Op_Profit × 100
