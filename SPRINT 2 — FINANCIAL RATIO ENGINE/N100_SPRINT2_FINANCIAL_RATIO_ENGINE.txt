KEY FORMULAS:

Net Profit Margin (NPM):
  NPM = (net_profit / sales) × 100
  Returns: None if sales = 0 or None
  Unit Tests: normal case, zero sales, negative profit

Operating Profit Margin (OPM):
  OPM = (operating_profit / sales) × 100
  Cross-check: Compare computed OPM with opm_pct column
  Log: If difference > 1%, log warning with company_id, year, difference
  Returns: None if sales = 0

Return on Equity (ROE):
  ROE = (net_profit / (equity_capital + reserves)) × 100
  Returns: None if equity + reserves ≤ 0
  Flag: If equity < 0, set negative_equity_flag = True
  Unit Tests: normal case, zero equity, negative equity

Return on Capital Employed (ROCE):
  ROCE = (EBIT / (equity + reserves + borrowings)) × 100
  Where EBIT = operating_profit
  Special Logic: For Financials sector, use sector-relative benchmark
  Returns: None if denominator ≤ 0

Return on Assets (ROA):
  ROA = (net_profit / total_assets) × 100
  Returns: None if total_assets = 0

KEY FORMULAS:

Debt-to-Equity (D/E):
  D/E = borrowings / (equity_capital + reserves)
  Special Case: If borrowings = 0, return 0 (NOT None)
  Flag: If D/E > 5 AND sector ≠ Financials, set high_leverage_flag = True
  For Financials sector: No high_leverage flag (leverage is normal)
  Unit Tests: debt-free returns 0, high D/E flag, financial sector exception

Interest Coverage Ratio (ICR):
  ICR = (operating_profit + other_income) / interest_expense
  Returns: None if interest_expense = 0
  Label: If ICR = None, set icr_label = "Debt Free"
  Flag: If 0 < ICR < 1.5, set icr_warning_flag = True
  Unit Tests: debt-free returns None with label, interest_coverage < 1.5 flag

Net Debt:
  Net Debt = borrowings - investments
  (Use investments as proxy for liquid assets)
  Returns: Can be negative if investments > borrowings

Asset Turnover:
  Asset Turnover = sales / total_assets
  Returns: None if total_assets = 0
  Interpretation: Sales generated per unit of assets

KEY FORMULAS:

Free Cash Flow (FCF):
  FCF = operating_activity + investing_activity
  (Note: investing_activity is negative for outflows)
  Returns: Can be negative (that's OK)
  Interpretation: Cash available after capex

CFO Quality Score:
  CFO Quality = (avg CFO over 5 years) / (avg PAT over 5 years)
  Thresholds:
    > 1.0    = "High Quality" (cash earnings > reported earnings)
    0.5-1.0  = "Moderate" (some working capital management)
    < 0.5    = "Accrual Risk" (cash earnings << reported earnings)
  Returns: None if PAT = 0

CapEx Intensity:
  CapEx Intensity = abs(investing_activity) / sales × 100
  (Use abs() to handle negative cf_investing)
  Thresholds:
    < 3%     = "Asset Light" (minimal capex needed)
    3-8%     = "Moderate" (normal capex)
    > 8%     = "Capital Intensive" (high capex required)
  Returns: None if sales = 0

FCF Conversion Rate:
  FCF Conv = FCF / operating_profit × 100
  Interpretation: % of operating profit converted to free cash
  Returns: None if operating_profit = 0

Capital Allocation Patterns (8 types):
  Signature: (CFO_sign, CFI_sign, CFF_sign)
  
  (+, -, -) = Reinvestor
    → Positive operating CF, negative investing CF (capex), negative financing CF
    → Using profits to invest in growth, no dividend/debt issuance
  
  (+, -, +) = Shareholder Returns
    → Positive operating CF, negative investing CF, positive financing CF
    → Excess cash returned to shareholders (dividends/buybacks)
  
  (+, +, -) = Liquidating Assets
    → Positive operating CF, positive investing CF (asset sales), negative financing CF
    → Selling assets, paying down debt
  
  (-, +, +) = Distress Signal
    → Negative operating CF, positive investing CF (asset sales), positive financing CF
    → Using asset sales and borrowing to fund operations (concerning)
  
  (-, -, +) = Growth Funded by Debt
    → Negative operating CF, negative investing CF (capex), positive financing CF
    → Early-stage/growth company funded by debt
  
  (+, +, +) = Cash Accumulator
    → All positive: strong operating cf, no major capex, borrowing or earning
    → Building cash reserves
  
  (-, -, -) = Pre-Revenue
    → All negative: no operating income, burning cash on capex, borrowing
    → Pre-revenue startup or distressed company
  
  (+, -, +) = Mixed/Complex
    → Combination that doesn't fit standard patterns
